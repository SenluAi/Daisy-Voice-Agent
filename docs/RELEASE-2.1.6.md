# Daisy 2.1.6

- 新增七天试用：首次联网登记，重装或删除本地缓存不重置同设备试用。
- 试用到期立即停止任务、录音、播报、唤醒和插件/MCP，只保留授权激活入口与退出。兑换码激活核验通过后恢复使用。
- 授权采用设备与请求绑定的 Ed25519 签名短期凭证，每小时联网续验，断网最长使用二十四小时有效凭证，且不超过试用截止。
- 加强缓存保护、时钟回拨检测、凭证篡改检测、服务器撤销检查与激活并发保护。私钥和 API Key 不包含在安装包中。
- 到期会取消 Daisy 正在执行的后台命令，不关闭用户正在使用的 QQ 等外部应用。
- 保留现有语音识别、Space 长按唤醒、连续对话、视觉自动化和 DSH 插件功能。

首次使用与凭证到期后需连接网络。当前安装版的模型配置和插件配置保持不变。

已完成授权单元测试、独立客户端到期/恢复测试和语音/插件/自动化回归。客户端防护提高破解成本，不能承诺绝对不可破解。
